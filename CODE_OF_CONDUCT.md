# Code of conduct

calamus follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good faith, and focus on the work. Harassment,
personal attacks and discriminatory language aren't welcome anywhere in this project.

## Reporting

To report behaviour that breaks the code of conduct, contact the maintainer,
[@justin-stanley](https://github.com/justin-stanley), privately by email (the address is on that
GitHub profile). Reports are kept confidential. The enforcement guidelines are those of the
Contributor Covenant 2.1.
